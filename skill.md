# Guided Gut Reset - Project Instructions and Guidelines

## 1. Technology Stack
- **Backend Framework:** Laravel 11
- **PHP Version:** PHP 8.3
- **Frontend Core:** HTML, Vanilla CSS, Vanilla JavaScript
- **Database:** SQL (MySQL/MariaDB via Laravel Eloquent/Query Builder)

## 2. Design and Reference Material
- **Reference Application:** [Guided Gut Reset Lovable App](https://guided-gut-reset-lovable-app.lovable.app/)
- **Objective:** Replicate the look, feel, and functionality of each page from the reference app identically.
- **Aesthetics:** The design must strictly adhere to the premium, clean, and dynamic feel of the reference app. Modern web design practices, appropriate color palettes, smooth micro-animations, and fully responsive layouts are mandatory.

## 3. Strict Rules & Agent Workflow
- **No Unprompted Code Execution:** Do not write, generate, or modify actual codebase files unless explicitly instructed by the user. Follow a step-by-step, planned approach.
- **Resource Gathering First:** Always update and consult the knowledge base/resources before beginning development on any new page or component.
- **Strict Tech Stack Adherence:** Do not use TailwindCSS, Alpine.js, Vue, React, or any other libraries/frameworks unless instructed. Stick strictly to Laravel Blade, Vanilla CSS, and Vanilla JS.
- **Code Quality:** Ensure PHP code adheres to PSR-12 standards and utilizes Laravel 11's modern features. Ensure HTML is semantic and CSS is strictly scoped or organized logically to avoid clashes.
